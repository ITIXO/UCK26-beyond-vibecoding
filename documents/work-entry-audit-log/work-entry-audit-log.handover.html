2 UX behaviour

History button

  • Present on every day row, including weekends and empty days
  • Toggle: click opens sidebar for that date; click again closes it
  • Switching to a different row's button swaps sidebar content
  • Active row highlighted with blue background
  • data-test-id: work-history-{date}

Sidebar

  • Overlays table (does not push layout)
  • Width: 300px, slides in from right
  • Events ordered descending by PerformedAt
  • Latest event expanded by default, others collapsed
  • Only one event open at a time (accordion)
  • Empty state: "No history for this day"
  • data-test-id: work-history-sidebar

Timeline events

  • ✦ Created — green dot, shows initial field values
  • ✎ Modified — blue dot, shows old → new per field
  • ✕ Deleted — red dot, shows tombstone with last known value
  • Entry type badge per event: work holiday doctor
  • data-test-id: work-audit-event-{index}

Deleted entries

  • Not shown in main table (history-only)
  • Appear in timeline with red delete event
  • All prior events for that entry still visible above delete event

4 AuditLog entity
public enum AuditAction { Create, Update, Delete }

public class AuditLog
{
    public int Id { get; set; }
    public string EntityType { get; set; } = "WorkEntry";
    public int EntityId { get; set; }
    public AuditAction Action { get; set; }
    public string PerformedBy { get; set; } = "";
    public DateTime PerformedAt { get; set; }    // UTC
    public string? ChangedFields { get; set; }  // JSON
    public string? EntryDate { get; set; }      // denorm
    public int? WorksheetId { get; set; }       // denorm
}

Key decisions

No FK to WorkEntry

AuditLog survives WorkEntry deletion. EntryDate + WorksheetId stored denormalized for querying.

PerformedBy = username string

Pulled from JWT name claim at write time. Survives user account deletion. Falls back to "system" when no HTTP context.

ChangedFields = JSON TEXT

Create: all initial values. Update: only modified fields (old+new). Delete: null.

5 API contract

Endpoint

GET /api/worksheets/{year}/{month}/days/{date}/audit
?userId=int  (admin only)

Returns 200 [] when no worksheet exists yet (not 404).

TypeScript contracts

type AuditAction =
  | 'Create' | 'Update' | 'Delete';

interface AuditChangedFieldDto {
  field: string;
  oldValue: string | null;
  newValue: string | null;
}

interface AuditLogEntryDto {
  entityId: number;
  action: AuditAction;
  performedBy: string;
  performedAt: string; // ISO 8601
  changedFields:
    AuditChangedFieldDto[] | null;
}
